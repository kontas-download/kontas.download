# kontas.download

Сайт и скачивание: https://kontas.download

Бесплатная бухгалтерская программа для литовских компаний, работающая на вашем собственном сервере. Все данные остаются у вас: они хранятся в одной базе SQLite на вашем компьютере или сервере, и программа не отправляет их во внешние сервисы. Интерфейс полностью работает на трёх языках: литовском, русском и английском.

Программа упакована для работы в контейнере Docker (Next.js 16, React 19, TypeScript, SQLite).

## Возможности

- **Продажи:** счета-фактуры продаж (SF), кредитовые счета (KS), периодические счета.
- **Закупки:** документы закупок, вычет PVM, кредитовые счета поставщиков, импорт электронных счетов поставщиков (UBL XML).
- **Режимы PVM:** плательщик PVM, неплательщик и SVS; продавец и покупатель могут быть плательщиками PVM независимо друг от друга. Налоговый статус исторических счетов сохраняется.
- **PDF и e-mail:** PDF счёта на языке покупателя (литовский, русский или английский); отправка по e-mail через SMTP компании-продавца; архив отправленных PDF. В PDF для клиента нет внутренних статусов оплаты и заметок.
- **Банк:** импорт банковских выписок (CSV, camt.053, MT940), привязка платежей к документам, расчёты вне банка.
- **Долги:** обзор дебиторской задолженности и напоминания.
- **Налоги:** экспорт i.SAF 1.2 XML, черновик FR0600, налоговые коды, налоговый календарь.
- **Учёт:** главная книга (журнал), оборотная ведомость, отчёт о прибыли и убытках и баланс, план счетов, акты сверки взаиморасчётов, закрытые периоды и история изменений.
- **Прочее:** контрагенты, склад и запасы, калькулятор зарплаты.
- **Несколько компаний:** неограниченное число компаний в одной программе, данные каждой изолированы.
- **Данные:** экспорт и импорт пакета компании, копия всей базы данных (для администратора).
- **Пользователи:** несколько пользователей, роли «администратор» и «бухгалтер», отключение учётной записи, ограничение попыток входа.

Подробная инструкция есть в справке самой программы (меню «Справка»).

## Ограничения

Программа не является налоговой или юридической консультацией; за декларации, учётную политику и правильность данных отвечают пользователь и его бухгалтер.

- Ничего **не подаётся в VMI автоматически**: нет подключения к EDS и i.MAS. Программа лишь готовит файл i.SAF XML и черновик FR0600, подавать их нужно самостоятельно.
- Нет подключения к Sodra.
- Нет дебетовых счетов (DS).
- Модуль зарплаты простой: предлагаемый расчёт упрощён (без NPD, прогрессивных ставок GPM и потолков Sodra), итоговые суммы вводите вы.
- Декларации PLN204, GPM312/GPM313 и FR0564 не готовятся; налоговый календарь только напоминает о сроках.
- В счёте нет автоматической отметки об обратном начислении (reverse charge) для услуг плательщику НДС из ЕС. Добавить её в PDF покупателя программа пока не позволяет (внутренние примечания в PDF не попадают), поэтому эту отметку и FR0564 оформляет бухгалтер.
- Нет автоматической амортизации основных средств и списания себестоимости запасов.
- Нет автоматической рассылки счетов по расписанию: каждая отправка выполняется вручную.

Подробнее: страница справки «Ограничения: чего программа не делает» и [docs/VMI-EDS-AUTOMATION.ru.md](docs/VMI-EDS-AUTOMATION.ru.md).

## Быстрый старт (Docker)

Нужен Docker с Compose v2.

```bash
docker compose up -d --build
```

Программа доступна по адресу **http://localhost:3200** (контейнер `kontas-app`; порт открыт только на 127.0.0.1).

При первом запуске на пустой базе программа создаёт стандартный литовский план счетов и администратора. E-mail по умолчанию — `admin@kontas.local`, **пароля по умолчанию нет**: случайный одноразовый пароль один раз выводится в журнал контейнера:

```bash
docker logs kontas-app
```

Войдите и сразу смените пароль (кнопка с ключом внизу бокового меню). Другой e-mail и пароль администратора (не короче 10 символов) можно задать переменными `ADMIN_EMAIL` и `ADMIN_PASSWORD` до первого запуска. Если пароль забыт:

```bash
docker exec -it kontas-app node scripts/set-password.cjs email@example.com
```

Чтобы сохранять пароли SMTP (для отправки счетов), до запуска задайте `SMTP_ENCRYPTION_KEY` (64 шестнадцатеричных символа; команда генерации есть в `web/.env.example`) и храните этот ключ отдельно от копий базы.

База хранится в каталоге `web/prisma` (том Docker), поэтому данные сохраняются при пересоздании контейнера. Сервер с HTTPS: см. [deploy/README.ru.md](deploy/README.ru.md).

## Локальная разработка

Нужен Node.js 22 (той же версии, что в Dockerfile).

```bash
cd web
npm install
cp .env.example .env        # DATABASE_URL, APP_ORIGIN
node scripts/bootstrap.cjs  # создаёт пустую базу и администратора (пароль выводится в консоль)
npm run dev
npm test
```

Подробнее о разработке: [web/README.ru.md](web/README.ru.md).
